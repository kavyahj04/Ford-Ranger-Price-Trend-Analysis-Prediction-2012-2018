# Contributing to AI-Bot-Agent

## Getting Started
1. Fork the repository
2. Clone: `git clone https://github.com/kavyahj04/AI-Bot-Agent`
3. Install dependencies: `pip install -r requirements.txt`
4. Create `.env` with required variables

## Making Changes
- Create a branch: `git checkout -b feature/your-feature-name`
- Commit your changes: `git commit -m "description"`
- Push and open a Pull Request

## Reporting Issues
Open a GitHub Issue with a clear description.
